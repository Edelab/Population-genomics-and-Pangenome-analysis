
# Phylogenetic tree construction from gene-based pangenome dataset across 55 isolates with *Spongospora subterranea* outgroup

### Overview

This pipeline builds a maximum-likelihood phylogenetic tree from single-copy orthologs (SCOs) identified by OrthoFinder across 56 genomes. Two trees are produced:

1. **All SCO genes** — 2,466 orthogroups
2. **Neutral genes only** — 888 orthogroups (genes not under selection)


## 1. OrthoFinder

Run OrthoFinder on all 56 protein FASTAs (`.fa` format):

```bash
orthofinder -f /path/to/directory/protein_fastas/ -t 20 -a 4
```

**Output used:** `Results_Mar06/Single_Copy_Orthologue_Sequences/`

---

## 2. MAFFT Alignment

**Script:** `mafft_align.sh`

```bash

#!/bin/bash

#SBATCH -J pb_orth
#SBATCH -o Pb-%j.out
#SBATCH -c 20
#SBATCH -p small
#SBATCH --mail-type=ALL
#SBATCH --mail-user=muhammad.javed.1@ulaval.ca
#SBATCH --time=1-00:00
#SBATCH --mem=150G

SCO_DIR="/path/to/directory/Results/Single_Copy_Orthologue_Sequences"
OUT_DIR="/path/to/directory/orthofinder_pb_vs_spongnospora/aligned_orthogroups"

module load mafft/7.525
mkdir -p "${OUT_DIR}"

total=$(ls "${SCO_DIR}"/*.fa 2>/dev/null | wc -l)
echo "[INFO] Found ${total} SCOs — starting alignment"

# 10 jobs x 2 threads = 20 cores
running=0
for f in "${SCO_DIR}"/*.fa; do
    base=$(basename "$f" .fa)
    mafft --auto --thread 2 "${f}" > "${OUT_DIR}/${base}_aln.fa" 2>/dev/null &
    running=$((running + 1))
    if (( running % 10 == 0 )); then
        wait
        echo "[INFO] ${running} / ${total} done..."
    fi
done
wait

done_count=$(ls "${OUT_DIR}"/*_aln.fa 2>/dev/null | wc -l)
echo "[INFO] Aligned: ${done_count} / ${total} orthogroups"
```


## 3. Extract Neutral Orthogroups

**Script:** `extract_neutral_orthogroups.py`

Filters orthogroups to only those containing genes not under selection (1,231 neutral gene IDs from Pn/Ps analysis):

```bash
python3 extract_neutral_orthogroups.py neutral_genes.txt \

```

## 4. Pre-trimming QC

**Script:** `check_alignments_qc.py`

Checks each alignment for: correct sequence count, gap percentage, alignment length, duplicate samples.

```bash
# All orthogroups
python3 check_alignments_qc.py ./reheadered_orthogroups --expected 56

# Neutral orthogroups
python3 check_alignments_qc.py ./only_neutral_core_genes --expected 56 --glob "*_aln.fa"
```


## 5. trimAl

**Script:** `trimal.sh`

Removes gaps and poorly aligned columns using `-automated1` (auto-selects between `-strict` and `-gappyout` per alignment):

```bash

#!/bin/bash

#SBATCH -J trimal
#SBATCH -c 8
#SBATCH -p small
#SBATCH --time=02:00:00
#SBATCH --mem=32G

IN_DIR="/path/to/directory/orthofinder_pb_vs_spongnospora/all_orthogroup_genes/all_reheadered_orthogroups"
OUT_DIR="/path/to/directory/orthofinder_pb_vs_spongnospora/all_orthogroup_genes/trimmed_orthogroups"

module load trimal/1.4
mkdir -p "${OUT_DIR}"

running=0
for f in "${IN_DIR}"/*_aln.fa; do
    base=$(basename "$f" _aln.fa)
    trimal -in "${f}" -out "${OUT_DIR}/${base}_trim.fa" -automated1 &
    running=$((running + 1))
    if (( running % 8 == 0 )); then
        wait
        echo "[INFO] ${running} trimmed..."
    fi
done
```


## 6. Concatenate Supermatrix

**Script:** `concat_supermatrix.py`

Concatenates all trimmed aligned OGs into a single supermatrix with partition file:

```bash
# All genes
python3 concat_supermatrix.py \
    ./all_orthogroup_genes/trimmed_orthogroups \
    ./supermatrix.fa \
    ./partitions.txt \
    AA

# Neutral genes
python3 concat_supermatrix.py \
    ./only_neutral_orthogroup/trimmed_neutral_orthogroups \
    ./neutral_supermatrix.fa \
    ./neutral_partitions.txt \
    AA
```


## 7. Supermatrix QC

**Script:** `qc_supermatrix.py`

Validates the supermatrix before IQ-TREE: checks partition contiguity, sequence lengths, alphabet, missing data, and per-gene occupancy.

```bash
python3 qc_supermatrix.py \
    ./neutral_supermatrix.fa \
    ./neutral_partitions.txt \
    --dtype AA \
    --aln-dir ./only_neutral_orthogroup/trimmed_neutral_orthogroups
```

## 8. Filter Partitions

**Script:** `filter_partitions_by_droplist.py`

Removes bad OGs (from `drop_partitions.txt` generated by QC) from the partition file:

```bash
# Fix file extension mismatch if needed
sed -i 's/\.fa$//' drop_partitions.txt

# Run filter
python3 filter_partitions_by_droplist.py
# Output: partitions.kept.txt
```

## 9. IQ-TREE2

**Command used:**

```bash
# All SCO genes tree
iqtree2 -s all_genes_supermatrix.fa \
        -p partitions.kept.txt \
        -m MFP \
        -rcluster 10 \
        -B 1000 \
        --alrt 1000 \
        -T 20 \
        --prefix pb_all_sco_genes_56_tree \
        --safe \
        -o spongospora

# Neutral genes tree
iqtree2 -s neutral_supermatrix.fa \
        -p neutral_partitions.kept.txt \
        -m MFP \
        -rcluster 10 \
        -B 1000 \
        --alrt 1000 \
        -T 20 \
        --prefix pb_neutral_sco_56_tree \
        --safe \
        -o spongospora
```
